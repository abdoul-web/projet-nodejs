# Application de gestion de dossiers médicaux

Application full-stack de gestion de dossiers médicaux : CRUD sur plus de 700
enregistrements, validation des données et classification par règles métier
exposée via API REST.

## Stack
- Backend : Node.js, Express
- Base de données : MongoDB
- Modèle : Python (scikit-learn) — `ml_model.py`, `ml_artifacts/`

## Lancer le projet
npm install
npm start
